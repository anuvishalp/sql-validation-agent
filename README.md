# SQL Validation Agent

A beginner-friendly Python project for checking database connectivity and validating SQL queries.

## Features

- Checks SQLite database connectivity.
- Parses SQL syntax using SQLGlot.
- Checks query plans for supported SELECT queries.
- Reports common database validation errors.
- Asks users to describe their expected results.
- Provides example SQL queries.

## Requirements

- Python 3.10 or newer
- pip

## Installation

Clone the repository and open its directory.

Create a virtual environment:

```powershell
python -m venv .venv
==================
